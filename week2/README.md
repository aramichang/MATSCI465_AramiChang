# Summary of Week 2 Assignment

4D STEM involves rastering a convergent electron beam across a sample and collecting an electron diffraction pattern at each raster point. This then enables virtual imaging post-data acquisition. By defining a virtual detector geometry (e.g. bright field imaging at the beam center, high angle annular dark field imaging at high-angle diffraction spots, etc.) and integrating the intensities of the diffraction spots using these detector geometries, a new image can be generated virtually and effectively allows one to "replay" the experiment.
